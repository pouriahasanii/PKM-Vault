# Setup

1. Copy this Vault into the local clone of `pouriahasanii/PKM-Vault`.
2. Open the folder as an Obsidian Vault.
3. Install only the initial Obsidian plugin set: Dataview, Templater, QuickAdd, and Excalidraw.
4. Keep GitHub Desktop as the only Git writer during initial rollout.
5. Configure QuickAdd to create `90 System/Templates/Universal Capture.md` in `00 Inbox`.
6. Back up `assets/` separately; it is intentionally excluded from Git.
7. Run `py "90 System/Scripts/validate_vault.py"` before the first commit.

## Logseq pilot

Open the same root folder as a Logseq graph only after making a backup. Use Markdown mode. Start with a read/annotation pilot on one device; do not edit the same note simultaneously in both applications.

Optional Logseq plugins after the native workflow is stable: Tabs, Bullet Threading, and Git. Do not make any plugin a dependency of the information architecture.
