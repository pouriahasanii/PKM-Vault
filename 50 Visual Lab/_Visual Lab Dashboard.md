# Visual Lab

Each visual project gets a folder under `50 Visual Lab/Projects/<project-id>/` containing:

- `00 Brief.md` — canonical intent and outcome
- `01 Visual Index.md` — links to every diagram
- `02 Decisions.md` — decisions extracted from visual work
- optional `.canvas`, `.excalidraw.md`, or Logseq whiteboard files

The corresponding project hub in `10 Projects` links here using the same `project_id`.
