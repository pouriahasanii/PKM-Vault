# PKM-Vault

A local-first, Git-ready personal knowledge system for Obsidian with a future-compatible Logseq layer.

Start with [`ARCHITECTURE.md`](ARCHITECTURE.md), then follow [`90 System/Guides/SETUP.md`](90%20System/Guides/SETUP.md).

## Golden rules

1. Capture first; classify later.
2. Markdown is the source of truth.
3. Secrets never enter the Vault or Git.
4. Attachments stay in `assets/` and are backed up separately.
5. A project, area, or resource has one canonical hub note.
